# 🧭 SmartVoyage: The Intelligent Trip Planner

**SmartVoyage** is an AI-powered travel planner designed to create optimized, personalized itineraries for users based on their preferences, budget, and location. It simplifies trip planning by offering real-time suggestions and safety features, all in a user-friendly interface.

## ✨ Features

- 🗓️ **Personalized Itineraries** – Get custom travel schedules based on your interests and budget
- 💰 **Smart Budget Planner** – Estimate your total trip cost (food, travel, stay)
- 🌐 **Offline Mode** – Access saved trips and maps without the internet
- 🧳 **AI-Powered Packing Suggestions** – Smart packing lists based on weather and activities

## 💻 Tech Stack

- **Frontend**: React.js (Vite), Tailwind CSS
- **Backend**: Firebase
- **Routing**: React Router
- **APIs Used**: Google Maps API, Generative AI API

## 🚀 Getting Started

### Clone the repository
git clone https://github.com/sagarrrrrrrr/trip-planner.git
cd trip-planner
Install dependencies
npm install
Run the app locally
npm run dev

🔥 Make sure to set up your environment variables for API keys in a .env file.
